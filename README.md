# Интернет-магазин детской зимней одежды

Полноценный локальный магазин на Node.js, Express, PostgreSQL, Prisma ORM, EJS, express-session, bcrypt и multer.

## Запуск

1. Установите зависимости:
```bash
npm install
```

2. Создайте базу PostgreSQL:
```bash
createdb kids_winter_shop
```

3. Создайте `.env`:
```bash
cp .env.example .env
```

При необходимости поправьте `DATABASE_URL`, `SESSION_SECRET` и `PORT`.

4. Выполните миграции и сгенерируйте Prisma Client:
```bash
npm run prisma:migrate
```

5. Заполните базу тестовыми данными:
```bash
npm run prisma:seed
```

6. Запустите проект:
```bash
npm run dev
```

Откройте `http://localhost:3000`.

## Возможности

- Каталог с поиском, фильтрами, сортировкой и пагинацией.
- Карточка товара с фото, вариантами, остатками, похожими товарами и отзывами.
- Регистрация, вход, личный кабинет, смена пароля и история заказов.
- Корзина в сессии для гостей и в базе для авторизованных пользователей.
- Промокоды, оформление заказа, списание и возврат остатков.
- Избранное.
- Админ-панель: товары, фото, категории, заказы, пользователи, отзывы, промокоды.
